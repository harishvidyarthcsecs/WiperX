Secure File & Folder Eraser

Overwrite-based deletion mapped to NIST SP 800-88 “Clear”. Each file is overwritten, truncated, renamed several times, then unlinked.

This permanently destroys the listed files. There is no undo.
Only paths inside {{ allowed_root }} may be targeted. Set WIPERX_ERASE_ALLOWED_ROOT to change this root.

Descend into every listed folder, erase all its files, then remove the emptied directory tree. Off = only plain files in the list are erased.
Overwrite pattern
Random-data overwrites written before the file is unlinked. NIST SP 800-88 Clear = 1 pass.
One all-zero pass written last, so the file's previous size / pattern can't be inferred from the overwrite itself.
